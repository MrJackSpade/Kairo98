# v1.5.3

- The D-pad is the arrow keys alone: it no longer moves the joystick at the same time. X and Y send their keys alone, and C and Z are the joystick's buttons 1 and 2.
- Every controller button sends one thing per press, in every game's default controls.

Install over v1.5.2 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
