# v1.3.1-test.5

Test build of Kairo98, for PC-98 games. It is not published to Google Play.

- Every setting the catalog gives a game is in its Game settings, where you can change it for that game: the clock, GDC, CPU, startup command, the game's own choices, disk swaps and drives.
- Startup commands and other text settings can take several lines.
- A long setting value is shortened on its row instead of the setting's name.
- The on-screen keyboard's joystick tab shows a joystick icon.
