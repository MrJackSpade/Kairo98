# Google Play listing: German (de-DE)

- **App name:** Kairo98

## Short description

Spielen Sie Ihre PC-98-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit Kairo98 spielen Sie Ihre eigenen PC-98-Spiele auf Android. Fügen Sie Ihre Datenträgerabbilder hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer PC-98-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele und Systemdateien sind nicht enthalten. Manche Spiele brauchen eine zusätzliche Einrichtung.

Sie können dieselbe App auch kostenlos über die GitHub Releases von Kairo98 herunterladen. Die Version bei Google Play hat dieselben Funktionen.

Kairo98 ist ein unabhängiges Projekt auf Basis von Neko Project 21/W und der Soundemulation ymfm.
