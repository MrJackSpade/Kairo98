# v1.4.2-test.1

Test build of Kairo98, for PC-98 games. It is not published to Google Play.

- Per-game System: the built-in BIOS or your own.
- Base clock and Skip memory check are machine options, with per-game overrides.
- The Disks page shows the drives of a loaded state.
- A hard disk boots with the floppy its catalog names.
- The emulator runs flat out while the game reads or writes its media.
- Direct touch clicks where you tap, and Auto touch mode notices when a game sets up the mouse.
- Library and folder texts name ZIP and 7z archives.
- Startup choices and disk swaps come from the catalog, and disk swaps are watched for the whole session.
- Adult games have a frank description of their adult content, in every language, in the builds that include adult content.
- The app is translated into Spanish, Portuguese (Brazil), German, Russian, Japanese, Korean, Arabic and Indonesian, and follows the device's language. In Arabic the layout reads right to left.
- Game descriptions are shown in the device's language, and on a Japanese device a game shows the Japanese title it was released under.
- Saves and settings belong to a game's path in the library, and a game opened from a frontend is the library's game, with its saves. A save state reopens its disks wherever they are now.
- Games are recognized by their content only, never by their file name.
- A game can be opened at the system's command line, with its media inserted and nothing typed or started.
- Disks page: Choose file puts a disk image from the device in any drive.
- The touch keyboard has a touchpad tab.
- The library lets the device sleep; the screen stays on only while a game is showing.
- A library search that matches nothing no longer crashes the app, and the library keeps the selected game in view when its list changes.

Install over v1.4.0 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
