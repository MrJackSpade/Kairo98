# Google Play listing: Japanese (ja-JP)

- **App name:** Kairo98

## Short description

Android で、お手持ちの PC-98 ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

Kairo98 は、お手持ちの PC-98 ゲームを Android で遊べるアプリです。ディスクイメージを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（PC-98 キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームとシステムファイルは含まれていません。一部のゲームには追加の設定が必要です。

同じアプリを Kairo98 の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

Kairo98 は、Neko Project 21/W と ymfm のサウンドエミュレーションを使った独立したプロジェクトです。
