# Google Play image sources

The four phone screenshots are made from the user-supplied phone captures in `docs/evidence/phone-*.jpg`. Their full frames are centered on black and scaled to 1080 × 1920 or 1920 × 1080 for Google Play; the app UI is not cropped or stretched. The feature graphic is a crop of an actual Retroid Pocket Classic capture in this repository. `tools/prepare_play_assets.ps1` records the exact sources and transformations. No image generation was used.

The Play app icon is a resize of the icon already shipped in the Android app. The screenshots depict a development build and user-provided PC-98 content; the non-artwork release does not bundle game files or catalog artwork. Review the final listing against the release build before submission.
