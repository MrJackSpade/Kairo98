# v1.3.1-test.1

Test build released alongside KairoDos v1.3.1-test.1. It is not published to Google Play.

- Kairo98 now runs on the frontend shared by every Kairo app, with a new icon.
- One library entry per game: a game's disks, and its other releases in the folder such as demos, music disks and other versions, sit behind its main release.
- Opening the app is faster: the library check reads again only the folders that changed, and archives are read in place instead of being copied to internal storage first.
- **Download missing images** shows its progress and failures, downloads several images at once, takes LaunchBox artwork first, and waits out a server's rate limit instead of counting it as a failure.
- **Menu › Machine › Skip memory check**, on by default, starts games without the PC-98's memory count.
- Controller defaults: A is Return, B is Space, X and Y are the joystick buttons, and the D-pad reaches the arrow keys.
- In a game with its own button mapping, **Controls** names that mapping and lists the all-games mapping separately.
- The D-pad scrolls settings pages and the menu with the selection, choice rows always show their ‹, and the controller icon no longer flashes after touching the bottom screen.
- Kairo98 tells you when a newer release is on GitHub.

Both APK variants have the same features.
