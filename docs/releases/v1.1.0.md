# v1.1.0

- Games with large catalog entries, such as Aegeankai no Shizuku, no longer trigger Android's "not responding" warning when they start, and the on-screen keyboard responds immediately instead of after several seconds.
- Kana now locks on a tap and switches the keyboard to the PC-98's kana legends, with the small kana and 「」、。・ under Shift. The alphabet page adds the - ^ \ and _ keys of the real layout, and Caps and Kana stay in step with the game, including after loading a saved state.
- Pressing a Shift symbol such as % now lights only that key, not the plain 5 that shares it.
- The game you last played now stays in ALL GAMES as well as under CONTINUE, and the pin updates whenever you return from a game.
- Deleting a game updates the library right away instead of rescanning the folder.
- The app returns to fullscreen after you switch back to it, as KairoDos already did.
- The library opens faster, and editing a game's title or artwork updates its library row immediately.

Install over v1.0.4 to keep games, settings and saves. The library is converted to a faster format the first time this version starts. Both APK variants and the Play bundle have the same features.
