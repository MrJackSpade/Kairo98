# v1.3.0

- Save states, game settings and each game's working disk now belong to the game's place in your ROM folder. Renaming or moving a game makes it a new game, and two copies of the same game no longer share save states.
- Editing a disk image no longer replaces the copy the game plays from, which holds what the game saved to its disk. **Game settings › Reset disk** replaces it with the current disk image.
- An edited disk keeps its catalog record, including its title, artwork and disk set.

Install over v1.2.2 or v1.2.3-test.1 to keep games, settings and saves. On first launch, existing save states, settings and working disks move to their games. If a save folder shared with another device already has a newer copy, Kairo98 asks which one to keep. Both APK variants and the Play bundle have the same features.
