# Google Play listing: Russian (ru-RU)

- **App name:** Kairo98

## Short description

Играйте в игры для PC-98 на Android с сенсорным управлением или геймпадом.

## Full description

Kairo98 позволяет играть в ваши собственные игры для PC-98 на Android. Добавьте свои образы дисков, выберите игру в библиотеке и играйте с геймпадом или с экранным управлением, включая клавиатуру PC-98. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры и системные файлы не входят в комплект. Некоторым играм нужна дополнительная настройка.

Это же приложение можно бесплатно скачать в GitHub Releases Kairo98. В версии из Google Play те же возможности.

Kairo98 — независимый проект на основе Neko Project 21/W и эмуляции звука ymfm.
