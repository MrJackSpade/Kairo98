# v1.0.0

- Redesigned menus: settings, game settings, disks and save states open as full pages with rows, inline choices and confirmations instead of dialogs and drawers.
- The game menu no longer has Resume and Keep paused buttons, because opening it already pauses the game. Return to library and Exit ask for confirmation in a dialog.
- New Menu › Configurations › Save folder setting keeps save states in private app storage or in a folder you choose. Changing it moves your save states there. If a slot is saved in both places, you choose which copy to keep before anything moves.
- Running games keep running when the device configuration changes, for example when you attach a keyboard, switch dark mode or change the display size. The RGDS second screen also stays open through these changes.
- A failed launch keeps its status in the library instead of clearing it.
- Choosing Library in a game started from an external frontend returns to that frontend.
- When Download missing images fails, the result names the reason, such as no internet connection.

Install over the previous signed Kairo98 release to keep games, settings and save states. Both APK variants and the Play bundle have the same features.
