- Changed the default controller layout: the left stick moves the mouse with speed that varies by tilt, and the right stick sends numpad 8/2/4/6.
- Added separate virtual left-stick directions so game mappings can assign the D-pad and left stick independently. Existing game profiles without left-stick assignments continue to follow their D-pad assignments.
- Steam Heart's now maps the D-pad and right stick to numpad 8/2/4/6 and the left stick to mouse movement.
- Existing custom controller mappings remain in effect after updating. Reset a custom mapping to use the new defaults.
