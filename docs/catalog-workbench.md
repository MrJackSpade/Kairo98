# Local catalog workbench

The PC-88 and PC-98 disk inventory and consolidated LaunchBox matches are documented in [catalog research](../catalog/research/README.md). The matching catalog is local research data; it is not the Android app's shipped catalog. The user will correct the final catalog before the next Git push.

`tools/catalog_workbench.py scan` hashes extracted HDI and supported floppy streams, so ZIP compression and metadata do not change their `sha256-hdi-v1` or `sha256-fd-v1` IDs. It reuses a prior hash only when archive size and modification time match; delete the ignored index to force a rehash. Existing HDI-only indexes are scanned again once to discover floppy entries, while unchanged HDI hashes are reused. It checks unsafe ZIP paths and per-image size and expansion limits. ZIPs without an image the app recognizes are labeled `no-supported-image`. Publisher ZIPs containing game ZIPs remain `nested-zip` until a nested-archive workflow is added. The NeoKobe PC-98 library uses publisher ZIPs, so the top-level publisher archive is not one game. [Issue #33](https://github.com/MrJackSpade/Kairo98/issues/33) tracks the remaining format work.

The local [LaunchBox database dump](https://gamesdb.launchbox-app.com/Metadata.zip) supplies title, alias, and image URL candidates. `tools/prepare_catalog_backlog.py` joins those against on-disk groups, and `tools/catalog_match.py` consolidates unambiguous exact title/alias links into `catalog/research/matches-v1.json`. The tool keeps each source group's platform and content IDs, and only stores media URLs. It does not open images, import media bytes, or copy LaunchBox overview text. The earlier, manually written descriptions remain in the catalog; new matches have empty descriptions until original text is written later.

The first pilot scanned 173 translated ZIPs: 147 had at least one HDI and 26 were floppy-only. It produced 130 translated title groups. The same title group can contain multiple archive variants and content IDs. The backlog builder can additionally split archives with separately named episode HDIs when given the translated hash index; combined multi-episode HDIs stay as separate groups. The research catalog links each episode hash to its own LaunchBox game record where possible.

The user will check identities and media choices from the consolidated catalog. A source URL alone grants no redistribution rights. Before packaging any image in the free or paid app, establish rights for both builds and any resizing or censorship. The current app catalog source format supports shared metadata and descriptions across multiple content IDs. `tools/import_art.py` enforces explicit art permissions; see [art rights](art-rights.md).
