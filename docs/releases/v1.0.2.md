# v1.0.2

- A `FONT.BMP` shipped with a game now loads automatically for that game. Kairo98 checks the game's ZIP, then its folders up to the ROM folder, and the copy nearest the disk image takes precedence over the font imported in **Machine** settings. The Machine menu shows "Game folder" while a game's own font is in use. A game font that is not a 2048x2048 monochrome BMP stops the launch with an error naming the file.

Install over v1.0.1 to keep games, settings and imported shaders. Both APK variants and the Play bundle have the same features.
