# Google Play listing: Indonesian (id)

- **App name:** Kairo98

## Short description

Mainkan game PC-98 Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

Kairo98 memungkinkan Anda memainkan game PC-98 milik Anda sendiri di Android. Tambahkan image disk Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard PC-98. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game dan file sistem tidak disertakan. Beberapa game memerlukan pengaturan tambahan.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases Kairo98. Versi Google Play memiliki fitur yang sama.

Kairo98 adalah proyek independen yang menggunakan Neko Project 21/W dan emulasi suara ymfm.
