# v1.6.2-test

Test build of Kairo98, for PC-98 games. It is not published to Google Play.

- Games whose disk images sit at a long path start: a game opened from a frontend such as ES-DE, or one with a long name in nested folders, no longer fails with "A disk image path is too long". Save states made by earlier versions still load.

Install over v1.6.1 or any v1.6.1 test build to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
