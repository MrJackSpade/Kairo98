# v1.4.0

- Games' startup commands and startup choices are typed by the same typer as Kairo88 and KairoTowns. A choice (such as Farland Story's Start game or Watch opening) is still answered on its own screen, and "Startup screen not recognized" still offers Retry.
- Skip memory check (on by default) starts games without the PC-98's memory count.
- Every game's D-pad reaches the arrow keys by default. Mappings follow a cascade: the PC-98 defaults, your all-games mapping, the game's catalog mapping, then your own for the game.
- Scaling anchor: Settings › Graphics pins the picture to any of nine places on the screen, separately for landscape and portrait, and each game's settings can choose its own. Pick it from a 3x3 grid.
- On a two-screen device (RG DS), the D-pad moves between the screens, and the bottom screen shows the selected game's page, then its settings once it is open.
- Disk swaps list the game's own disks first.
- The library scan is faster, shows its progress, and no longer copies every archive to internal storage to inspect it.

Install over v1.3.0 or any v1.3.1 test build to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
