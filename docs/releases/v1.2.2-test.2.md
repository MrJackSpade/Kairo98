# v1.2.2-test.2

Test build for [#60](https://github.com/MrJackSpade/Kairo98/issues/60). It is not published to Google Play.

- Audio no longer crackles during normal play. Kairo98 ran every game at 60 frames a second, but the PC-98's normal display runs at 56.4, so games ran about 6% fast and part of each frame's sound was thrown away. Games now run at the PC-98's own refresh rate and keep all of their sound.
- Audio no longer clicks when a frame takes longer than usual. Sound now plays from a queue that covers slow frames, instead of waiting on the audio device.

Install over v1.2.1 or v1.2.2-test.1 to keep games, settings and saves. Both APK variants have the same features.
