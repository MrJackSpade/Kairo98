# v1.6.1-test.3

Test build of Kairo98, for PC-98 games. It is not published to Google Play.

- No changes for Kairo98 itself: this build keeps every Kairo app on the same version.

Install over v1.6.1-test.2, v1.6.1-test or v1.6.0 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
