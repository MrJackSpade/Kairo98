# v1.2.0

- CD-ROM games: the machine now has an IDE CD-ROM drive, and the library reads CloneCD images (a `.ccd` with its `.img`, in a folder or a ZIP). Starting a game puts its CD in the drive, and starting a CD boots the disk that runs it. **Menu › Disks › CD-ROM** changes or ejects the disc.
- A multi-disk game now appears as one library entry, started from its hard disk or disk 1. Its other disks remain available for disk swaps, boot floppies, drive B and the Floppy A/B menus.
- The catalog now recognizes 19,657 disks by their contents, up from 216, covering almost every disk in the NeoKobe PC-98 collection, including CD versions and their boot floppies. Games without a database record are titled after their folder.
- Startup choices and automatic disk swaps now recognize their screens whichever font is loaded. Before, a game such as Night Slave could wait forever at its music driver menu without an imported FONT.BMP.

Install over v1.1.1 to keep games, settings and saves. The library keeps its existing scan, and **Menu › Manage library › Refresh** finds CD images already in your folder. Both APK variants and the Play bundle have the same features.
